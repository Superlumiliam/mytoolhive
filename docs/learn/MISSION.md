# Mission: ToolHive 企业级工具治理与社区贡献

## Why
掌握 ToolHive 如何把 MCP server 从“可以运行的工具”变成“可准入、可隔离、可控制、可审计、可规模化运营的企业能力”，并能在真实仓库中独立定位、实现和验证社区贡献。

## Success looks like
- 能从企业治理视角解释 ToolHive 的核心架构、信任边界与主要取舍
- 能沿一条真实请求或生命周期调用链，从命令入口走读到关键 Go 实现与测试
- 能独立完成一个范围清晰的小型 CLI、核心包或 Operator 贡献
- 能按项目规范验证改动并提交易评审的 PR
- 能评审一个 Operator、认证授权或 vMCP 设计中的安全、状态与扩展性取舍

## Constraints
- 已具备 MCP 基础概念，不重复教授协议入门
- 架构与方法优先，但每个主题都要落实到“带新同事走读代码”式实现细节
- 基础阶段优先覆盖企业治理主链；低频、锦上添花或非常复杂的能力放入高阶
- 所有课程材料、学习偏好和学习记录统一保存在 `docs/learn/`

## Out of scope
- 基础阶段不穷举所有 CLI 参数、CRD 字段或实验性能力
- 不把记忆代码细节当作掌握；重点是能定位边界、验证假设和完成贡献
- 不复制产品架构文档；课程以链接、代码走读和练习编排现有事实源
