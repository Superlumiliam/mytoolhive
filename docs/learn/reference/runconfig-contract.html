RunConfig 控制面契约速查

一句话：RunConfig 保存可移植的运行意图，但执行时仍需注入 runtime、解析受管理秘密并连接外部资源；wire decode、builder validation 和 runtime rehydration 是三层不同保证。

inputs → builder/defaults/validation → RunConfig → WriteJSON/state/ConfigMap │ ▼ ReadJSON/limited migration → runtime injection → secret resolution → Runner

变更前的三个检查

入口一致性
CLI、API、Operator、import、proxy-runner 是否采用同一默认/验证语义？
版本与迁移
旧 JSON 如何读取？新 reader 是否保留旧意图？不能把 schema 字段存在当作已实现兼容门。
导出保真
JSON export 接近 wire round-trip；K8s export 是有损模型转换，必须检查 warning 与字段映射测试。
