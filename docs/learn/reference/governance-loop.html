企业 MCP 工具治理闭环

1

发现与准入

Registry、provider、provenance 与 policy gate 决定“允许使用什么”。

2

可移植配置

RunConfig 把来源、参数、transport、权限和 middleware 变成可验证契约。

3

隔离运行

Runtime、permission profile、network 与 secrets 决定“以什么权限执行”。

4

流量控制

Proxy、transport 与 middleware 决定“谁能以何种方式调用什么”。

5

生命周期与证据

Workload state、status、logs、audit 与 telemetry 让运行可运营、可追责。

6

规模化协调

Operator 用声明式资源持续收敛期望状态；vMCP 在更高层聚合工具入口。

判断题：如果一个系统只完成第 3 步，它是安全的企业治理平台吗？答案是否定的：隔离只是闭环的一环。
