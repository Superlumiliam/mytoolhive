统一走读法

  1. 说清业务场景和不可破坏的不变量。
  2. 画调用流或数据流，只标边界。
  3. 先读接口和关键结构体，再走 5–8 个 happy-path 函数。
  4. 读相邻测试，确认真正契约而非注释印象。
  5. 制造一个失败场景，口述应该改哪一层以及为什么。
