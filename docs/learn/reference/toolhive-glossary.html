ToolHive 统一术语表

课程中的术语以仓库 Core Concepts 为事实源。

Workload
ToolHive 管理的完整部署单元：MCP server、proxy 以及配置与状态，而不等同于单个容器。
RunConfig
描述 workload 如何运行的可移植配置契约，连接 CLI 输入、持久化状态和执行层。
Runtime
实际创建与管理隔离工作负载的执行后端，例如 Docker/Podman 或 Kubernetes。
Transport
MCP 消息如何跨边界传输，例如 stdio、SSE、streamable HTTP。
Proxy
位于 client 与 MCP server 之间的流量边界，负责协议桥接或透明转发，并承载 middleware。
Middleware
按顺序处理请求/响应的治理管线，例如认证、授权、过滤、审计与遥测。
Registry
经组织策展与策略约束的 MCP server 来源；在治理语境中不只是搜索目录。
Permission Profile
限制 workload 文件系统、网络和运行权限的最小权限策略。
Operator
把 Kubernetes CRD 的期望状态持续协调为实际资源和 status condition 的控制器。
Virtual MCP Server (vMCP)
把多个后端 MCP server 聚合为统一端点的网关，并处理路由、冲突、session 与双边身份。
