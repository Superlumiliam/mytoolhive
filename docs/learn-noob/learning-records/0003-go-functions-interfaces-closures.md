# Go 函数值、接口、闭包与中间件基础

用户已建立 Go 中函数值、`http.Handler` 接口、`http.HandlerFunc` 适配器、匿名函数和闭包的基础理解：函数可以像值一样传递，接口定义能力契约，闭包由函数代码和捕获的外部变量环境组成；每次创建闭包会形成独立环境。用户还理解了 ToolHive 中间件是“装饰器 + 责任链”模式，掌握了 `tokenSource`、`next`、`w/r` 分别在中间件创建、链组装和请求到达阶段传入，并认识到简单依赖可用闭包传递，复杂依赖和生命周期应使用结构体、接口和 `context.Context` 显式表达。后续可在此基础上学习 Go 方法、接口实现、指针/值接收者和实际中间件链代码。
